방문자 숫자 전수 조사 보고서
================================================================================

■ 1. 우리가 받아오는 숫자 (API)

  • 엔드포인트: GET https://multishop-rho.vercel.app/api/visitors
  • 출처: Google Analytics Data API (GA4)
  • 지표: totalUsers
  • 두 개의 조회:
    - today: startDate="today", endDate="today" → 오늘 00:00 ~ 현재까지의 총 사용자 수
    - total:  startDate="2020-01-01", endDate="today" → 누적 총 사용자 수

  → 이 숫자는 GA4 속성 기준으로 "해당 기간에 한 번이라도 방문한 사용자 수"이며,
    GA4 대시보드의 [보고서] → [참여도] 등에서 보는 "사용자" 수와 같은 정의입니다.
    정확한 GA4 집계 값입니다.

--------------------------------------------------------------------------------

■ 2. GA4 "실시간" 숫자와 다른 이유

  • GA4 실시간 보고서: "지난 30분 동안의 활성 사용자" (Active users in last 30 minutes)
  • 우리 API "오늘": "오늘 00:00 ~ 지금까지의 총 사용자" (totalUsers for today)

  → 정의가 다릅니다.
    - 실시간 2명 = 지금 막 보고 있는 사람 2명
    - 오늘 10명 = 오늘 하루 동안 방문한 사람 10명 (지금은 안 보고 있어도 포함)
  → 따라서 실시간 숫자 ≠ 오늘 숫자 이며, 둘 다 맞는 값입니다.

--------------------------------------------------------------------------------

■ 3. Vercel 페이지 vs GitHub Pages 페이지 숫자가 다른 이유 (원인)

  [확인 결과]

  • Vercel (https://multishop-rho.vercel.app/)
    - 같은 도메인에 /api/visitors 가 있으므로 fetch("/api/visitors") 로 API 호출 성공
    - 또는 visitor-api-config.js 에 베이스 URL이 있어 동일 API 호출
    → 화면에는 GA4에서 받은 today, total 이 표시됨 (모든 접속자에게 동일)

  • GitHub Pages (https://choiplea-droid.github.io/multishop/index.html)
    - 실제 배포된 visitor-api-config.js 내용:
      window.VISITOR_API_BASE = "";   ← 빈 문자열
    - 따라서 fetch("" + "/api/visitors") = fetch("/api/visitors")
      → 상대 URL이라 https://choiplea-droid.github.io/multishop/api/visitors 로 요청
    - GitHub Pages에는 /api/visitors 엔드포인트가 없음 → 404, fetch 실패
    - script.js 는 실패 시 .catch() 로 무시하고, localStorage 값만 그대로 둠
    → 화면에는 "기기별 localStorage" 숫자만 표시됨

  • localStorage 숫자의 의미 (script.js)
    - 오늘 첫 방문 시: total += 1, today += 1 저장 (해당 기기에서만)
    - 날짜가 바뀌면 today 는 0으로 리셋, total 은 유지
    - 기기·브라우저마다 따로 저장되므로, 폰/PC/다른 사람마다 전부 다른 숫자

  결론: GitHub Pages 쪽은 "API를 전혀 호출하지 못하고" 기기별 localStorage 만 보여주고 있어서
        Vercel(GA4 숫자)과 항상 다르고, 기기마다도 서로 다릅니다.

--------------------------------------------------------------------------------

■ 4. 어떤 숫자가 "정확한지"

  • "전체/오늘 방문자 수"로 쓰려면 → API가 반환하는 GA4 totalUsers(today, total) 가 정확합니다.
  • "지금 동시 접속자"로 쓰려면 → GA4 실시간 보고서 숫자가 정확합니다.
  • 우리 사이트 상단 바는 "오늘 / 총 방문" 이므로, API(GA4 totalUsers)가 맞는 기준입니다.
  • GitHub Pages 에 보이는 숫자는 API가 아닌 기기별 localStorage 이므로, "공식 방문자 수"로 보면 안 됩니다.

--------------------------------------------------------------------------------

■ 5. 해결 방법 (GitHub Pages 에서도 같은 숫자로 맞추려면)

  • GitHub Pages 에 배포되는 저장소(choiplea-droid.github.io 또는 multishop 배포용 repo)에서
    visitor-api-config.js 를 수정해야 합니다.

  • 현재 (배포된 파일):
    window.VISITOR_API_BASE = "";

  • 수정 후:
    window.VISITOR_API_BASE = "https://multishop-rho.vercel.app";

  • 저장 후 해당 저장소 push → GitHub Pages 재배포하면,
    해당 페이지에서도 Vercel API를 호출하게 되어 모바일/PC 모두 GA4와 동일한 숫자가 표시됩니다.

--------------------------------------------------------------------------------

■ 6. 요약 표

  구분              | 숫자 출처              | 표시 의미
  ------------------+------------------------+----------------------------------------
  API 응답          | GA4 totalUsers         | 오늘/전체 방문자 수 (정확한 집계)
  Vercel 페이지     | API 호출 성공 → 위와 동일
  GitHub Pages 페이지 | API 호출 실패 → localStorage | 기기별 로컬 카운트 (공식 수 아님)
  GA4 실시간        | GA4 실시간 보고서     | 지난 30분 활성 사용자 (동시 접속 개념)
